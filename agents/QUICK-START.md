# 🚀 Quick Start - Usando os Agentes no Cursor

## ✅ Sistema Configurado!

O sistema de roteamento automático de agentes já está configurado e funcionando no Cursor IDE.

## 🎯 Como Usar (3 Formas)

### 1️⃣ **Detecção Automática** (Mais Fácil)

Simplesmente descreva sua tarefa. O sistema detecta automaticamente qual agente usar:

```
💬 "Corrigir erro 500 na rota /api/reservations"
→ Automaticamente usa: Backend Specialist Agent

💬 "Melhorar layout do formulário no mobile"
→ Automaticamente usa: Frontend Specialist Agent

💬 "Criar migration para nova tabela"
→ Automaticamente usa: Database & Security Specialist Agent
```

### 2️⃣ **Especificação Explícita**

Mencione o agente que você quer usar:

```
💬 "Como Backend Specialist: otimizar query do Supabase"

💬 "Como Frontend Specialist: corrigir componente quebrado"

💬 "Como Testing Specialist: criar testes para a API"
```

### 3️⃣ **Múltiplos Agentes**

Para tarefas complexas que precisam de múltiplos agentes:

```
💬 "Criar feature completa de avaliações"
→ Sistema usa: Backend + Frontend + Database agents em colaboração
```

## 🎯 Dicas

1. **Seja específico**: Quanto mais detalhes, melhor o roteamento
2. **Mencione arquivos**: "Corrigir erro em `app/api/reservations/route.ts`"
3. **Descreva o problema**: "Erro 500 ao criar reserva"
4. **Mencione contexto**: "No mobile, o formulário está quebrado"

```

```

O assistente deve responder identificando o **TypeScript & Code Quality Specialist Agent**.
